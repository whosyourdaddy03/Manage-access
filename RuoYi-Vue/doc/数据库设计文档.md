# 数据库设计文档

## 1. 数据库概述

### 1.1 数据库信息
- **数据库名称**: `seer`（在 Mapper XML 中引用）
- **数据库类型**: MySQL 8.x
- **字符集**: UTF-8（utf8mb4）
- **存储引擎**: InnoDB（支持事务、外键、行级锁）

### 1.2 表结构总览

| 表名 | 中文名 | 核心用途 | 数据量预估 |
|------|--------|----------|-----------|
| annotations | 标注数据表 | 存储图片标注信息（坐标、尺寸、姿态等） | 大（万级+） |
| annotations_epoch_results | 训练轮次结果表 | 存储 YOLOv8 训练过程中每个 epoch 的指标数据 | 中（千级） |
| annotations_training_tasks | 训练任务表 | 存储训练任务的元数据和配置信息 | 小（百级） |
| model_registry | 模型注册表 | 管理已训练模型的注册信息和状态 | 小（百级） |

### 1.3 表关系图
```
annotations          annotations_epoch_results
    │                        │
    │ (按id前缀)             │ (id 关联)
    │ 关联分组               │
    ▼                        ▼
数据集列表                annotations_training_tasks
                                    │ (taskId 关联)
                                    ▼
                              model_registry
                              (training_task_id)
```

## 2. 表结构详细设计

### 2.1 annotations（标注数据表）

**用途**: 存储图片的标注信息，包括边界框坐标、图片尺寸、姿态信息等。

**DDL**:
```sql
CREATE TABLE `annotations` (
  `id` varchar(20) NOT NULL COMMENT '图片ID（主键），如 0100001、0200100',
  `width` int(11) DEFAULT NULL COMMENT '图片宽度（像素）',
  `height` int(11) DEFAULT NULL COMMENT '图片高度（像素）',
  `depth` int(11) DEFAULT NULL COMMENT '图片深度（颜色通道数，通常为3）',
  `segmented` tinyint(4) DEFAULT NULL COMMENT '是否分割标注（0=否，1=是）',
  `xmin` int(11) DEFAULT NULL COMMENT '标注框左上角 X 坐标',
  `xmax` int(11) DEFAULT NULL COMMENT '标注框右下角 X 坐标',
  `ymin` int(11) DEFAULT NULL COMMENT '标注框左上角 Y 坐标',
  `ymax` int(11) DEFAULT NULL COMMENT '标注框右下角 Y 坐标',
  `pose` varchar(20) DEFAULT NULL COMMENT '姿态类型（如 Unspecified）',
  PRIMARY KEY (`id`)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='标注数据表';
```

**字段说明**:

| 字段名 | 类型 | 允许空 | 说明 |
|--------|------|--------|------|
| id | varchar(20) | NO | 图片唯一标识，格式：前2位为数据集编号，后5位为序号 |
| width | int(11) | YES | 原始图片宽度，如 3840 |
| height | int(11) | YES | 原始图片高度，如 2160 |
| depth | int(11) | YES | 颜色深度，通常为 3 (RGB) |
| segmented | tinyint(4) | YES | 是否为分割标注，0=否（边界框），1=是（多边形分割） |
| xmin | int(11) | YES | 标注框在图片中的最小 X 坐标 |
| xmax | int(11) | YES | 标注框在图片中的最大 X 坐标 |
| ymin | int(11) | YES | 标注框在图片中的最小 Y 坐标 |
| ymax | int(11) | YES | 标注框在图片中的最大 Y 坐标 |
| pose | varchar(20) | YES | 人体姿态类型，如 Unspecified / Standing / Sitting |

**常用 SQL**:
```sql
-- 按数据集（id前缀）分组统计图片总数
SELECT SUBSTRING(id, 1, 2) AS folder, COUNT(*) AS totalCount
FROM seer.annotations
GROUP BY SUBSTRING(id, 1, 2)
ORDER BY folder;

-- 查询单个图片的标注信息
SELECT id, width, height, `depth`, segmented, xmin, xmax, ymin, ymax, pose
FROM seer.annotations
WHERE id = '0100001';
```

### 2.2 annotations_epoch_results（训练轮次结果表）

**用途**: 存储 YOLOv8 训练过程中每个 epoch 的详细指标数据，是 Dashboard 图表的直接数据源。

**DDL**:
```sql
CREATE TABLE `annotations_epoch_results` (
  `id` varchar(50) NOT NULL COMMENT '训练任务ID，如 train9',
  `epoch` int(11) NOT NULL COMMENT '轮次数（从1开始）',
  `time` float DEFAULT NULL COMMENT '该轮次耗时（秒）',
  `train_box_loss` float DEFAULT NULL COMMENT '训练集 Box Loss',
  `train_cls_loss` float DEFAULT NULL COMMENT '训练集分类损失',
  `train_dfl_loss` float DEFAULT NULL COMMENT '训练集 DFL 损失',
  `metrics_precision_B` float DEFAULT NULL COMMENT '精确率 (Precision)',
  `metrics_recall_B` float DEFAULT NULL COMMENT '召回率 (Recall)',
  `metrics_mAP50_B` float DEFAULT NULL COMMENT 'mAP@0.5 指标',
  `metrics_mAP50_95_B` float DEFAULT NULL COMMENT 'mAP@0.5:0.95 指标',
  `val_box_loss` float DEFAULT NULL COMMENT '验证集 Box Loss',
  `val_cls_loss` float DEFAULT NULL COMMENT '验证集分类损失',
  `val_dfl_loss` float DEFAULT NULL COMMENT '验证集 DFL 损失',
  `lr_pg0` float DEFAULT NULL COMMENT '学习率（参数组0）',
  `lr_pg1` float DEFAULT NULL COMMENT '学习率（参数组1）',
  `lr_pg2` float DEFAULT NULL COMMENT '学习率（参数组2）',
  PRIMARY KEY (`id`, `epoch`)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='训练轮次结果表';
```

**字段说明**:

| 字段名 | 类型 | 允许空 | 说明 |
|--------|------|--------|------|
| id | varchar(50) | NO | 训练任务标识，与训练任务表关联 |
| epoch | int(11) | NO | 当前是第几个训练轮次 |
| time | float | YES | 该轮次的训练耗时，单位秒 |
| train_box_loss | float | YES | 训练集边界框损失（衡量框回归精度） |
| train_cls_loss | float | YES | 训练集分类损失（衡量分类精度） |
| train_dfl_loss | float | YES | 训练集 DFL（Distribution Focal Loss）损失 |
| metrics_precision_B | float | YES | Precision（精确率），值范围 [0, 1] |
| metrics_recall_B | float | YES | Recall（召回率），值范围 [0, 1] |
| metrics_mAP50_B | float | YES | mAP@0.5，IoU阈值0.5时的平均精度 |
| metrics_mAP50_95_B | float | YES | mAP@0.5:0.95，IoU阈值从0.5到0.95的平均精度 |
| val_box_loss | float | YES | 验证集边界框损失 |
| val_cls_loss | float | YES | 验证集分类损失 |
| val_dfl_loss | float | YES | 验证集 DFL 损失 |
| lr_pg0 | float | YES | 参数组0的学习率（通常为主干网络） |
| lr_pg1 | float | YES | 参数组1的学习率（通常为头部网络） |
| lr_pg2 | float | YES | 参数组2的学习率（通常为偏置项） |

**常用 SQL**:
```sql
-- 查询所有不同的训练任务ID
SELECT DISTINCT id FROM seer.annotations_epoch_results ORDER BY id;

-- 查询指定训练任务的所有 epoch 结果（按轮次排序）
SELECT id, epoch, `time`, train_box_loss, train_cls_loss, train_dfl_loss,
       metrics_precision_B, metrics_recall_B, metrics_mAP50_B, metrics_mAP50_95_B,
       val_box_loss, val_cls_loss, val_dfl_loss, lr_pg0, lr_pg1, lr_pg2
FROM seer.annotations_epoch_results
WHERE id = 'train9'
ORDER BY epoch;

-- 查询最新一条 epoch 记录（Dashboard 统计卡片使用）
SELECT * FROM seer.annotations_epoch_results
WHERE id = (SELECT MAX(id) FROM seer.annotations_epoch_results);

-- 查询所有 epoch 结果（Dashboard 全量数据）
SELECT id, epoch, `time`, train_box_loss, train_cls_loss, train_dfl_loss, ...
FROM seer.annotations_epoch_results
ORDER BY id, epoch;
```

### 2.3 annotations_training_tasks（训练任务表）

**用途**: 存储训练任务的元数据，包括训练参数、模型路径等。任务 ID 通过 `syncTaskIds` 从 epoch 结果表同步。

**DDL**:
```sql
CREATE TABLE `annotations_training_tasks` (
  `id` varchar(50) NOT NULL COMMENT '任务ID（主键），如 train9',
  `training_time` datetime DEFAULT NULL COMMENT '训练开始时间',
  `model_version` varchar(20) DEFAULT NULL COMMENT '模型版本，如 YOLOv8s',
  `epochs` int(11) DEFAULT NULL COMMENT '总训练轮次',
  `batch_size` int(11) DEFAULT NULL COMMENT '批次大小',
  `image_size` int(11) DEFAULT NULL COMMENT '输入图片尺寸（边长，如640）',
  `best_pt_path` varchar(500) DEFAULT NULL COMMENT '最优模型文件路径（best.pt）',
  `last_pt_path` varchar(500) DEFAULT NULL COMMENT '最近模型文件路径（last.pt）',
  `create_time` datetime DEFAULT NULL COMMENT '记录创建时间',
  PRIMARY KEY (`id`)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='训练任务表';
```

**字段说明**:

| 字段名 | 类型 | 允许空 | 说明 |
|--------|------|--------|------|
| id | varchar(50) | NO | 训练任务唯一标识，如 train9、train10 |
| training_time | datetime | YES | 训练开始的具体时间 |
| model_version | varchar(20) | YES | 使用的模型版本配置 |
| epochs | int(11) | YES | 训练计划的总轮次数，如 300 |
| batch_size | int(11) | YES | 每批次样本数，如 16 |
| image_size | int(11) | YES | 模型输入的图片尺寸，如 640（表示 640x640） |
| best_pt_path | varchar(500) | YES | best.pt 文件的绝对路径，用于模型注册或下载 |
| last_pt_path | varchar(500) | YES | last.pt 文件的绝对路径，用于模型注册或下载 |
| create_time | datetime | YES | 该记录的创建时间，同步时自动填充 |

**常用 SQL**:
```sql
-- 查询所有训练任务（训练任务列表页）
SELECT id, training_time, model_version, epochs, batch_size, image_size,
       best_pt_path, last_pt_path, create_time
FROM seer.annotations_training_tasks
ORDER BY id;

-- 根据ID查询任务详情
SELECT * FROM seer.annotations_training_tasks WHERE id = 'train9';

-- 从 epoch 结果表同步任务ID（避免重复）
INSERT IGNORE INTO seer.annotations_training_tasks (id, model_version, epochs, batch_size, image_size)
SELECT DISTINCT r.id, 'YOLOv8s', 300, 16, 640
FROM seer.annotations_epoch_results r
WHERE r.id IS NOT NULL AND r.id != '';

-- 更新模型文件路径
UPDATE seer.annotations_training_tasks
SET best_pt_path = 'D:\\models\\train9\\weights\\best.pt',
    last_pt_path = 'D:\\models\\train9\\weights\\last.pt'
WHERE id = 'train9';
```

### 2.4 model_registry（模型注册表）

**用途**: 统一管理训练产出的模型文件，支持注册、启用/归档切换和版本对比。

**DDL**:
```sql
CREATE TABLE `model_registry` (
  `id` bigint(20) NOT NULL AUTO_INCREMENT COMMENT '自增主键',
  `model_name` varchar(100) NOT NULL COMMENT '模型名称，如 Det-Fly 基准模型 V1.0',
  `model_version` varchar(20) DEFAULT NULL COMMENT '模型版本号，如 1.0',
  `model_type` varchar(20) DEFAULT NULL COMMENT '模型类型，如 YOLOv8s / YOLOv8n / YOLOv8m',
  `source_path` varchar(500) NOT NULL COMMENT '模型文件绝对路径',
  `training_task_id` varchar(50) DEFAULT NULL COMMENT '关联的训练任务ID',
  `metrics_mAP` double DEFAULT NULL COMMENT 'mAP50 评估指标',
  `metrics_speed` double DEFAULT NULL COMMENT '推理速度（毫秒）',
  `status` varchar(20) DEFAULT 'archived' COMMENT '状态：in_use=使用中, archived=归档',
  `remark` varchar(500) DEFAULT NULL COMMENT '备注信息',
  `create_time` datetime DEFAULT NULL COMMENT '创建时间',
  `update_time` datetime DEFAULT NULL COMMENT '更新时间',
  PRIMARY KEY (`id`)
) ENGINE=InnoDB AUTO_INCREMENT=1 DEFAULT CHARSET=utf8mb4 COMMENT='模型注册表';
```

**字段说明**:

| 字段名 | 类型 | 允许空 | 说明 |
|--------|------|--------|------|
| id | bigint(20) | NO | 自增主键，自动生成 |
| model_name | varchar(100) | NO | 模型的业务名称，方便识别 |
| model_version | varchar(20) | YES | 语义化版本号 |
| model_type | varchar(20) | YES | 模型架构类型 |
| source_path | varchar(500) | NO | .pt 文件在磁盘上的绝对路径 |
| training_task_id | varchar(50) | YES | 关联的训练任务，用于溯源 |
| metrics_mAP | double | YES | 模型的 mAP@0.5 指标值，用于版本对比 |
| metrics_speed | double | YES | 模型的推理速度（毫秒/张），用于版本对比 |
| status | varchar(20) | YES | 当前使用状态，同一时间只有一个 in_use |
| remark | varchar(500) | YES | 备注说明 |
| create_time | datetime | YES | 注册时间 |
| update_time | datetime | YES | 最近更新时间 |

**常用 SQL**:
```sql
-- 查询所有模型（按状态和创建时间排序）
SELECT id, model_name, model_version, model_type, source_path,
       training_task_id, metrics_mAP, metrics_speed, status, remark,
       create_time, update_time
FROM seer.model_registry
ORDER BY status DESC, create_time DESC;

-- 查询使用中的模型（推理服务使用）
SELECT * FROM seer.model_registry WHERE status = 'in_use' LIMIT 1;

-- 切换模型为使用中（事务：先清除所有 in_use，再设置指定模型）
UPDATE seer.model_registry SET status = 'archived' WHERE status = 'in_use';
UPDATE seer.model_registry SET status = 'in_use', update_time = NOW() WHERE id = 5;

-- 扫描本地目录中的未注册模型（NOT EXISTS 反连接）
SELECT 'D:\\models' AS dir_path, f.file_name,
       CONCAT('D:\\models\\', f.file_name) AS full_path
FROM (SELECT 'best.pt' AS file_name UNION SELECT 'last.pt') f
WHERE NOT EXISTS (
    SELECT 1 FROM seer.model_registry m
    WHERE m.source_path = CONCAT('D:\\models\\', f.file_name)
);

-- 注册新模型
INSERT INTO seer.model_registry (model_name, model_version, model_type, source_path,
                                 training_task_id, metrics_mAP, metrics_speed, status, remark, create_time)
VALUES ('Det-Fly 基准模型 V1.0', '1.0', 'YOLOv8s', 'D:\\models\\best.pt',
        'train9', 0.8123, 12.5, 'archived', '初始版本', NOW());
```

## 3. 索引设计

| 表名 | 索引名 | 字段 | 类型 | 说明 |
|------|--------|------|------|------|
| annotations | PRIMARY | id | 主键索引 | 图片ID唯一标识 |
| annotations_epoch_results | PRIMARY | (id, epoch) | 联合主键 | 任务ID+轮次唯一 |
| annotations_epoch_results | idx_id | id | 普通索引 | 按任务ID查询加速 |
| annotations_training_tasks | PRIMARY | id | 主键索引 | 任务ID唯一标识 |
| model_registry | PRIMARY | id | 主键索引 | 自增主键 |
| model_registry | idx_status | status | 普通索引 | 按状态查询加速 |

## 4. 数据同步与维护

### 4.1 训练任务同步
```
过程：epoch 结果表 -> INSERT IGNORE -> 训练任务表
频率：用户手动触发（点击"同步任务"按钮）
SQL：SELECT DISTINCT id FROM annotations_epoch_results 
      INSERT IGNORE INTO annotations_training_tasks
```

### 4.2 模型文件扫描
```
过程：指定目录 -> NOT EXISTS 比对 -> 未注册文件列表
触发：用户点击"扫描本地"按钮
算法：将目录中的 best.pt / last.pt 与 model_registry.source_path 逐一比对
```

## 5. 数据安全

### 5.1 SQL 注入防护
- 全部使用 MyBatis 参数绑定 `#{id}`，杜绝字符串拼接
- 框架层 `SqlUtil` 工具类检测 SQL 注入关键字

### 5.2 权限控制
- 框架层 JWT Token 认证保护非 `@Anonymous` 接口
- MySQL 用户权限分离（应用账户仅 DML 权限）

### 5.3 数据备份建议
```sql
-- 定期备份 seer 数据库
mysqldump -u root -p seer > seer_backup_$(date +%Y%m%d).sql

-- 备份指定表
mysqldump -u root -p seer annotations_epoch_results > epoch_results_backup.sql
```

## 6. SQL 示例汇总

### 6.1 Dashboard（首页）
```sql
-- 1. 获取所有训练任务 ID 列表
SELECT DISTINCT id FROM seer.annotations_epoch_results ORDER BY id;

-- 2. 获取最新一条记录的指标（统计卡片）
SELECT metrics_mAP50_B, metrics_mAP50_95_B, metrics_precision_B,
       metrics_recall_B, train_box_loss, val_box_loss
FROM seer.annotations_epoch_results
WHERE id = (SELECT MAX(id) FROM seer.annotations_epoch_results);

-- 3. 按任务分组获取 epoch 结果（图表）
SELECT * FROM seer.annotations_epoch_results
WHERE id = 'train9' ORDER BY epoch;
```

### 6.2 数据集
```sql
-- 数据集列表（按 ID 前缀统计）
SELECT SUBSTRING(id, 1, 2) AS folder,
       CONCAT('Det-Fly ', SUBSTRING(id, 1, 2)) AS name,
       COUNT(*) AS totalCount
FROM seer.annotations
GROUP BY SUBSTRING(id, 1, 2)
ORDER BY folder;
```

### 6.3 标注查询
```sql
-- 查询图片标注信息
SELECT id, width, height, `depth`, segmented, xmin, xmax, ymin, ymax, pose
FROM seer.annotations
WHERE id = '0100001';
```

### 6.4 模型注册
```sql
-- 查询未注册的模型文件（与已注册路径对比）
SELECT 'D:\\weights' AS dir_path, f.file_name,
       CONCAT('D:\\weights\\', f.file_name) AS full_path
FROM (SELECT 'best.pt' AS file_name UNION SELECT 'last.pt') f
WHERE NOT EXISTS (
    SELECT 1 FROM seer.model_registry m
    WHERE m.source_path = CONCAT('D:\\weights\\', f.file_name)
);

-- 清空使用中状态 + 设置新使用中模型（事务）
START TRANSACTION;
UPDATE seer.model_registry SET status = 'archived' WHERE status = 'in_use';
UPDATE seer.model_registry SET status = 'in_use', update_time = NOW() WHERE id = 5;
COMMIT;
```
